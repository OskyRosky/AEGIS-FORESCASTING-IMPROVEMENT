# metrics/

Aggregated metric tables comparing candidates against the champion (ETS Explicit) and baselines.

- `candidate_metrics_by_model.csv` — per-candidate median/mean MASE, RMSSE, sMAPE, bias, negative_forecast_count, runtime_seconds.
- `candidate_vs_champion.csv` — head-to-head deltas vs ETS Explicit and best baseline.
- Written by the V3.2C harness ONLY. Empty until V3.2C runs.
- Diagnostic/experimental only. No promotion, no governance change.
