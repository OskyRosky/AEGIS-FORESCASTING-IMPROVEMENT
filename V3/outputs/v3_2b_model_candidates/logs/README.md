# logs/

Execution logs (stdout/stderr) per candidate and per stage from the V3.2C harness.

- One log per candidate run (e.g. `FNAR-V2_subset.log`, `FNAR-V2_full.log`).
- Written by the V3.2C harness ONLY. Empty until V3.2C runs.
- Used to trace fit errors, convergence warnings, and failure reasons.
